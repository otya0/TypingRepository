# Task 2: Relevant Pairs of Products

## Overview
Find the more relevant pair of products. Calculate the number of purchases for all pairs of products purchased at the same time, and show them in descending order.

## Input
- Same format as Task 1, but queries ask for pairs of products.

## Output
- For each query, output pairs sorted by purchase count (descending), then dictionary order.

## Constraints
- 1 <= N <= 100, 1 <= M <= 10, 1 <= length of p <= 10, 1 <= Q <= 10
